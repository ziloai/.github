# Zilo

We build smart rings. Two product lines:

- **Zilo** — health ring for everyday wellbeing · [ziloring.com](https://ziloring.com)
- **OpenZilo** — the open-source AI ring dev kit for developers and researchers · [openzilo.com](https://openzilo.com)
